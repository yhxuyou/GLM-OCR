🏥 项目背景

我们需要处理医疗文档 OCR

❌

遇到的问题：
  • 医疗文档（化验单、病历）识别准确率低
  • 文档经常倾斜、旋转、畸变
  • 需要保留文字的坐标位置信息
  • glmocr 原有的 Pipeline 功能不够用

💡 核心诉求：在不改原源码的基础上，增加预处理和后处理能力

💭 初步想法

我的第一反应是这样跟 AI 说的

👤 我：

"我要创建一个新项目叫 medical_ocr，参考 glmocr 的 pipeline，写一个自己的 pipeline 类"

📝 一开始我只是模糊地说了需求，没有具体说明：

  • ✗ 具体要继承哪些类
  • ✗ 需要保留什么功能
  • ✗ 预处理和后处理具体做什么

🔄 AI 的第二次尝试

这次开始正确了

🤖 AI：

好的，我现在理解了：

  • 1. 创建一个新目录 medical_ocr
  • 2. 创建继承自 glmocr 原有类的子类
  • 3. 在子类中添加预处理/后处理逻辑
class MedicalPipeline(Pipeline): # ✅ 继承 def process(self, request_data): # 先预处理 images = self.preprocess(images) # 调用父类逻辑 results = super().process(request_data) # 后处理 return self.postprocess(results)

📝 需求细化

我需要明确说明具体功能

👤 我：

"不需要 pipeline 改动推理逻辑，只需要写一个 PageLoader 子类，对图片进行预处理，包括三个部分：

  1. 文档检测 YOLO 模型
  2. 扭曲矫正 UVDoc 模型
  3. 文档方向检测 RapidOCR"

初始化时需要对这些模型进行初始化"

# AI 看到 glmocr.Pipeline 的 __init__ 后理解了结构 class MedicalOcrPipeline(Pipeline): # ✅ 继承自 glmocr.Pipeline def __init__(self, config, yolo_model_dir=None, uvdoc_model_dir=None): # 关键：只在 __init__ 替换组件，其他完全继承 self.page_loader = MedicalPageLoader(config.page_loader, ...) self.layout_detector = MedicalLayoutDetector(config.layout) self.result_formatter = MedicalResultFormatter(config.result_formatter) # 其他属性从父类复制 self.max_workers = config.max_workers self._page_maxsize = getattr(config, "page_maxsize", 100)

✅ AI 学会了：通过看源码，理解了如何继承

🔄 继续迭代

LayoutDetector 的需求

👤 我：

"layout_detector 也和原来一样，只重写 process 方法。子类的逻辑是：

  1. 先运行父类的 process
  2. 只保留 label 为 'table' 的 region
  3. 再保留整个图片为一个 region，label 设置为 'text'

💡 明确规则："先...再..." 这样的流程描述 AI 最容易理解

✅ LayoutDetector 实现

简洁清晰的代码

class MedicalLayoutDetector(PPDocLayoutDetector): def process(self, images, ...): # Step 1: 调用父类 process all_results, vis_images = super().process(images, ...) # Step 2: 只保留 "table" label filtered = [r for r in all_results if r["label"].lower() == "table"] # Step 3: 添加全图作为 "text" filtered.append({ "label": "text", "bbox_2d": [0, 0, 1000, 1000], ... }) return filtered, vis_images

💎 核心经验

AI 编码最重要的三件事

1️⃣ 给上下文 - 让 AI 看到参考代码

2️⃣ 分步骤描述 - 用清晰的流程说明需求

3️⃣ 迭代优化 - 不对就继续沟通调整

🤔 一些思考

AI 是助手，不是替代者

AI 擅长：快速生成代码、理解代码结构、执行重复任务

人需要做：描述需求、判断方案、检查结果、把握方向

沟通能力比编码能力更重要

学会清晰地描述问题，是高效使用 AI 的关键

不要害怕迭代
