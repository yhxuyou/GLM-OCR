01 项目背景

医疗文档处理的挑战

📋 传统处理痛点

  • 文档倾斜、旋转无法自动矫正
  • 透视畸变无法处理
  • 文字识别准确率低
  • 缺乏结构化坐标信息
  • 无法处理复杂表格

🏥 医疗文档特点

  • 化验单、病历、检查报告
  • 包含大量表格和数字
  • 需要高精度结构化提取
  • 需要保留原始位置信息

MedicalPageLoader

三阶段图像预处理

class MedicalPageLoader(PageLoader): """继承 glmocr.dataloader.PageLoader""" def preprocess_image(self, image): # 1. YOLO 文档检测 → 裁剪文档区域 bbox = self.detect_document(image) processed = self.crop_document(image, bbox) # 2. RapidOCR 方向矫正 → 旋转至正确角度 processed = self.correct_orientation(processed) # 3. UVDoc 畸变矫正 → 平坦化透视变形 processed = self.correct_distortion(processed) return processed
✅ 自动检测并裁剪文档 → 自动矫正倾斜 → 自动矫正透视畸变

MedicalLayoutDetector

布局检测后处理

class MedicalLayoutDetector(PPDocLayoutDetector): """继承 glmocr.layout.PPDocLayoutDetector""" def process(self, images, ...): # Step 1: 调用父类获取所有检测结果 all_results = super().process(images) # Step 2: 过滤 - 只保留 label 为 "table" 的区域 filtered = [r for r in all_results if r["label"].lower() == "table"] # Step 3: 添加整个图片作为 "text" 区域 filtered.append({ "label": "text", "bbox_2d": [0, 0, 1000, 1000], ... }) return filtered

MedicalResultFormatter

RapidOCR 坐标匹配

class MedicalResultFormatter(ResultFormatter): def __init__(self, config): super().__init__(config) # 初始化 RapidOCR 模型 from rapidocr_onnxruntime import RapidOCR self._rapidocr = RapidOCR() def format_ocr_result(self, content, image): # 使用 RapidOCR 检测文字坐标 detected = self._detect_text_with_coordinates(image) # 返回带坐标的结果 return { "content": "识别的文字", "bbox_2d": [100, 50, 400, 80], "polygon": [[100,50], [400,50], ...] }
✅ 输出结果包含精确的坐标信息，便于后续结构化处理

MedicalOcrPipeline

流程编排（仅修改 __init__）

class MedicalOcrPipeline(Pipeline): """继承 glmocr.pipeline.Pipeline""" """所有 process() 逻辑完全继承父类""" def __init__(self, config, yolo_model_dir=None, uvdoc_model_dir=None): # 替换为医疗专用组件 self.page_loader = MedicalPageLoader(...) # ✅ 替换 self.layout_detector = MedicalLayoutDetector(...) # ✅ 替换 self.result_formatter = MedicalResultFormatter(...) # ✅ 替换 # 其他逻辑完全继承父类，不做任何修改！
关键优势：保持 glmocr 原有推理逻辑不变，只需替换 Pipeline 类即可

05 使用指南

快速集成（仅需 3 步）

Step 1：安装依赖
pip install glmocr pip install rapidocr_onnxruntime # 坐标检测 pip install ultralytics # YOLO 检测（可选）
Step 2：替换 Pipeline（仅此一行）
# 原代码 from glmocr.pipeline import Pipeline # 新代码（仅改这一行） from medical_ocr import MedicalOcrPipeline
Step 3：运行（代码完全不变）

完整代码示例

from medical_ocr import MedicalOcrPipeline from glmocr.config import load_config # 加载配置并创建 Pipeline config = load_config() pipeline = MedicalOcrPipeline( config=config.pipeline, yolo_model_dir="/path/to/yolo", uvdoc_model_dir="/path/to/uvdoc" ) # 启动并处理 pipeline.start() for result in pipeline.process(request_data): print(result.json_result) # 带坐标的 JSON print(result.markdown_result) pipeline.stop()
✅ 关键点：其余代码完全不变，只需替换 Pipeline 类
